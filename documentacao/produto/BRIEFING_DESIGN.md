# Briefing de design — cores vigentes

O formato claro anterior substitui o tema escuro do briefing inicial por decisão do usuário. Esta revisão altera somente cores; tamanhos, componentes, cantos, espaçamentos e estrutura permanecem como estão. A fonte pode ser personalizada conforme a atualização abaixo.

| Aplicação | Cor |
|---|---|
| Fundo geral | `#F7F8FC` |
| Cards, formulários e popups de conteúdo | `#FFFFFF` |
| Texto principal | `#20263B` |
| Texto secundário | `#626B83` |
| Roxo principal | `#6250EC` |
| Verde dos contatos | `#059B73`, com texto branco |
| Bordas | `#DFE3EE` |
| Superfícies secundárias | `#F1F3F9` |
| Erros | `#B43E3E` |
| Avisos | Texto `#886025` sobre `#FCF0D8` |
| Cabeçalho | `#101627`, com texto branco |
| Faixa de busca | Gradiente original: `#17172F`, `#15152E`, `#151C30` |
| Títulos sobre fotos | `#FFFFFF` |

A busca utiliza campo branco com texto escuro. Fotos ampliadas preservam fundo escuro e legenda clara, como no formato anterior. A identidade da vitrine permanece configurável com prévia e ajuste automático opcional da cor do texto; a cor padrão foi restaurada para o roxo anterior.


## Personalização e acesso — revisão da validação

Cor principal e cor do texto dos botões são independentes. O gestor pode escolher Inter, Arial, Verdana, Georgia ou a fonte do sistema. A prévia informa visualmente o resultado; o botão Ajustar cor do texto automaticamente escolhe preto ou branco para facilitar a leitura. Não exibir mensagens técnicas de proporção de contraste como bloqueio ao usuário.

O acesso fica em um ícone minimalista de usuário ao lado do seletor da vitrine. Login e senha aparecem em popup. Campos usam borda `#DFE3EE`; foco suave `#B7AFD5`, sem contorno amarelo/laranja. Itens ativos de navegação usam a identidade da vitrine e a cor de texto escolhida.
