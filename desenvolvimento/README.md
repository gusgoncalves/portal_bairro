# Materiais de desenvolvimento

modelos/: arquivos de referência distribuídos com o framework, fora da operação atual; copiar para a raiz e ajustar os caminhos somente se for utilizá-los.
historico/: roteador antigo e materiais de apresentação preservados.

Os testes automatizados estão em ../tests. Ferramentas locais, entregas e metadados auxiliares permanecem em ../storage e não devem ser publicados. Dependências são reinstaladas por Composer; vendor não é versionado.
